Project Overview

A demo video walkthrough is available here:

This project is built using Next.js, along with Redux Toolkit and Redux Thunk for state management. It demonstrates key concepts such as:

Adding and deleting data across different components
Managing add & delete operations within the same component
Persisting data using localStorage
Debugging and inspecting state using Redux DevTools
Getting Started

First, run the development server:

npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev

Open http://localhost:3000 in your browser to view the application.

You can start editing by modifying:

app/page.js

The page will automatically update as changes are made.

Tech Stack
Framework: Next.js
State Management: Redux Toolkit, Redux Thunk
Storage: localStorage
Debugging: Redux DevTools
